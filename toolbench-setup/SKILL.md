# 工具台搭建（Toolbench Setup）

## 原则
1. **最小可开工（MVK, Minimum Viable Kit）**：只列做完 L0-L1 项目必需的东西，其余全部进"延后"。
2. 每件都要写：**为什么现在需要 / 不买的后果 / 便宜替代 / 什么时候升级**。
3. 二手与借用优先；仪器类先用最低档跑通流程，再按具体瓶颈升级。
4. 明确标注**智商税**（学习期完全不需要的高端件）。
5. **器材不齐不是不开工的理由** —— 必须给出"没有 X 时的替代练习"。

## 输出格式

```
【MVK 清单】总预算 ¥____（够做完 L0-L1）
| 物品 | 型号/档位 | 价位 | 为什么现在必需 | 便宜替代 | 升级触发条件 |

【延后清单】（触发条件：当你要做 ___ 时再买）
| 物品 | 为什么可以等 | 触发条件 | 预算 |

【智商税提示】
- ____：学习期不需要，理由：____

【软件/环境】
安装顺序：1) 2) 3)
常见安装坑：
手机端可行方案：（纯 Android 能做什么）

【安全须知】
（按学科给：触电/高压/储能电容/焊接烟雾/激光/化学品/锂电池等）
```

## 电子工程参考基线（示例，需按用户预算调整）

**MVK**
- 数字万用表（中低档即可）
- 面包板与杜邦线
- 常用阻容包
- 可调直流电源（或 USB 电源模块）
- 温控焊台
- 斜口钳/镊子/吸锡带
- 护目镜

**第二波（触发式）**
- 入门数字示波器 —— 触发：需要看波形/时序而不只是电压
- 逻辑分析仪 —— 触发：调 I2C/SPI/UART 时序
- 电子负载/信号发生器 —— 触发：做电源或放大器测试
- 热风枪 —— 触发：开始拆焊贴片

**软件**
- KiCad（免费且社区资源丰富）
- LTspice 或 ngspice（仿真）
- 打样厂工艺能力表（设计前必读）

**智商税提示**
学习期不需要高端台式示波器、进口高精度万用表、昂贵商业 EDA 授权。

**一手源必备**
把用到的每颗器件的 Datasheet 与 Errata 下载到工作区，比多买一件仪器更值钱。

**安全**
- 不带电改接线
- 储能电容先放电
- 焊接开窗或用抽烟仪
- 市电项目在没有隔离变压器与经验前不要做
- 锂电池不短路、不过充、不扎穿

## 铁律
- 预算未知时先问"这门课你愿意投多少钱"，给 3 档方案（省 / 标准 / 舒适）。
- 任何单件超过总预算 40% 的东西，必须给出"延后 + 替代"路径。
- 手机为主的学习者：优先在线仿真、云 IDE、纸笔推演 + 拍照记录，先把认知打通再投硬件。
- 输出后立即交回 project-ladder，用 MVK 能做的 L0 项目当天开工。
- 不推荐"全套学习套件"，那通常是溢价包装。
