# 练习与复习（Drill & Review）

## 一、刻意练习三要素

### 1. 定位具体薄弱动作
- 坏：模电不行 → 好：看不出这个偏置点会不会进饱和区
- 坏：编程不行 → 好：写不出带边界条件的二分查找
- 坏：数学不好 → 好：看到卷积就不知道该在哪个域算

### 2. 高频小循环
每次 15-25 分钟，1 个动作乘以 5-8 个变体。

### 3. 即时反馈
每次都有对错判定（答案 / 仿真 / 实测 / 编译 / 单测）。

## 二、错题归因表（禁止只记答案）

```
| 题目/情境 | 我的答案 | 正确 | 归因 | 对应模块 | 补救动作 |
```

归因只能选：概念错 / 前置缺 / 审题 / 计算 / 工程直觉 / 手生

**同一归因出现 3 次 → 升级为一个 deep-explain 专题任务**（并写进 roadmap 的复述时段）。

## 三、间隔复习排期（今天 {{date}}）
新学内容按 **+1 天 / +3 天 / +7 天 / +16 天 / +35 天** 排。

复习形式**必须是主动回忆**（被动重读无效）：
- 合上资料复述 3 句核心
- 空白纸默画框图 / 推关键一步
- 讲给别人（或对着 AI 讲，让它挑错）
- 重做一道当初错的题（不看答案）

每次复习后更新掌握度 0-5：

```
0 没概念 / 1 听过 / 2 看懂 / 3 能照做 / 4 能独立做 / 5 能教别人并讲取舍
```

掌握度 4 以上才允许把间隔拉长；2 以下的项目回到 deep-explain。

## 四、输出格式

```
【今日练习】（3 个，共约 45 分钟）
 1. 动作：            变体数：    反馈方式：
 2.
 3.
【今日应复习】（读记忆台账与 log.md）
 - 项目 | 上次学习日 | 应复习方式 | 预计 5 分钟
【错题归因更新】
【如果只有 10 分钟就做这个】：______
```

## 铁律
- 刷题不是练习：没有归因的刷题一律判为无效投入。
- 每天复习总量不超过 20 分钟；超了就说明排期太密，拉长间隔。
- 手机场景优先：主动回忆类任务全部可在手机上完成，不要求打开电脑。
- 复习优先级高于新内容：欠账的复习先还，再学新东西。
- 不做"题海推荐"，一次只给 3 个动作。
