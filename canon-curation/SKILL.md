# 正典甄选（Canon Curation）

## 资料分级（每份都必须打标签）
- **T0 主线（最多 3 个）**：全程反复回看 —— 1 本主教材 + 1 个视频/讲座源 + 1 套练习/实验源
- **T1 参考**：查阅式，不通读 —— 数据手册、AppNote、标准、API 文档、手册型教材
- **T2 深挖**：主线打通后再碰 —— 专著、论文、进阶专题
- **T3 娱乐**：维持热情用 —— 拆机视频、项目 vlog；**必须标注"不产生能力"**
- **X 排除**：讲错 / 过时 / 营销课；写明排除理由

## 每份资料的档案

```
标题 / 作者 / 年份 / 版本：
定位：T0 / T1 / T2 / T3 / X      适配起点：
凭据：（谁在用它、被哪些课程指定、哪位老兵推荐过、出处）
读法：读哪几章、跳哪几章、配套做什么动作
体量与预计耗时：（页数/时长 → 按用户周投入折算周数）
获取方式：（正规渠道优先；有中译本则注明版本与术语差异）
```

## 视频课筛选四问（过不了 2 关就降级到 T3 或 X）
1. 作者**做过**真东西吗（有作品/产品/仓库），还是只讲过？
2. 有翻车、调试、失败过程吗？（只有成功演示 = 没有教到判断力）
3. 年份是否过时？器件/框架/标准是否已迭代？
4. 有配套练习、源码、工程文件吗？

## 铁律
1. **T0 上限 3 个**。超了就是资源囤积症，必须现场砍掉并说明砍谁、为什么。
2. **一手 > 二手**：标准文本、厂商 AppNote、经典原著 > 转述型教程与"精讲课"。
3. 有疑问的资料一律交给 source-vetting 打分后再定级。
4. 输出**必须包含"现在不要看"清单**，每项写清"什么条件达成后再看"。
5. 中英并列时提示：术语差异、版本差异、勘误表在哪。
6. 免费一手源优先于付费课程；只有在"省时间"能被量化时才推荐付费。
7. 不给"资源合集""网盘全套"，那是决策疲劳的来源。

## 输出格式
- T0 三件套（含读法与耗时折算）
- T1 参考架（按用途分类，5-8 项）
- T2 解锁清单（含解锁条件）
- T3 兴趣补给（1-2 个）
- X 排除清单（含理由）
- 存档：courses/<课程名>/library.md

## 完成判定
用户能说出"我这周只用这三样东西"，并把其余资料关进 T2/T3 抽屉。
